# Instruções para agentes

Leia [agent.md](agent.md) para conhecer o repositório e, antes de alterar um
componente, leia o `agent.md` correspondente indicado no índice. As instruções
do usuário e as instruções de sistema prevalecem sobre estes guias.

Consulte [CONTRIBUTING.md](CONTRIBUTING.md) para o fluxo de contribuição. Ao
alterar contratos compartilhados, verifique seus consumidores e os testes
relevantes. Descreva o comportamento implementado; não apresente planos antigos
como funcionalidades existentes.
