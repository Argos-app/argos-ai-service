# Documentação — guia para agentes

Os guias de API, Mongo, operação, Docker, Kubernetes e deploy descrevem
contratos ou procedimentos atuais. Arquivos com nomes de plano ou resultados de
validação podem conter decisões históricas e evidências de datas específicas.
Confira implementação, configurações e testes antes de tratá-los como estado
atual.

Ao alterar um contrato ou procedimento, atualize a documentação afetada e seus
exemplos sem remover contexto histórico válido. Não inclua chaves ou dados de
usuários. O [índice da raiz](../agent.md) aponta para os guias de cada
componente.
